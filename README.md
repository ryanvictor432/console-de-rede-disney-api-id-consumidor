# 🏰 API ConsumerDisneyId

Uma aplicação de consola desenvolvida em **C#** que consome a API pública da Disney para consultar informações de personagens. Este projeto realiza a consulta específica do personagem com o ID **423**, extraindo e exibindo o seu nome e o URL da respetiva imagem.

---

## ⚙️ Pré-requisitos
* Ter instalado no sistema o **.NET SDK 8** (ou versão superior).

## 🚀 Como Executar
Abra o seu terminal na pasta raiz do repositório e execute o seguinte comando:

```bash
dotnet run --project ConsumerDisneyIdApi/ConsumerDisneyIdApi.csproj
